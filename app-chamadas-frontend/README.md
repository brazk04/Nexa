# Coworking Platform — frontend

React, TypeScript e Vite. A documentação de execução, arquitetura, eventos, testes e limites da V1 está no [README principal](../README.md).

```powershell
npm ci
npm run dev
```

Verificação: `npm run lint`, `npm run build` e `npm test` (Playwright com Chrome instalado). Os testes iniciam um backend e um frontend isolados, sem alterar o banco de desenvolvimento.
